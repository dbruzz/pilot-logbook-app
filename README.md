
# Altora ✈️

Altora is a digital pilot logbook that helps pilots record flights, monitor progress, and achieve their flying goals.

Built with Next.js, Supabase, TypeScript, and Tailwind CSS.

## Features

- ✈️ Flight log management
- 📊 Dashboard with flight statistics
- 🎯 Flight time, distance, and flight count goals
- 🛩️ Aircraft management
- 📖 Flight journal with images
- 📄 Pilot documents (licenses, certificates, ratings)
- 🌐 English and Spanish support
- 🔐 Secure authentication with Supabase

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- PostgreSQL
- Vercel

## Getting Started

Install dependencies:

```bash
npm install
# or
yarn install
```

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Run the development server:

```bash
npm run dev 
# or
yarn dev
```

Open http://localhost:3000 with your browser to see the result.
